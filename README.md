# ShopCore - Django & Bootstrap E-Commerce Platform

ShopCore, Django tabanlı modern bir e-ticaret web uygulaması ve REST API altyapısıdır. Projede ürün kataloğu, dinamik kategori yönetimi, Bootstrap 5 destekli duyarlı (responsive) arayüzler ve genişletilebilir kullanıcı modeli yer almaktadır.

## Özellikler

- **Özel Kullanıcı Modeli (`CustomUser`):** `AbstractUser` üzerinden genişletilmiş satıcı/müşteri rol ve adres yönetimi.
- **Ürün & Kategori Yönetimi:** Kategorilere göre filtrelenebilir, stok ve aktiflik durumuna göre dinamik ürün listeleme.
- **Modern Web Arayüzü (Frontend):**
  - **Ürün Kataloğu (`product_list.html`):** Bootstrap 5 kart tasarımları, stok bildirim rozetleri ve dinamik filtreleme.
  - **Ürün Detay Sayfası (`product_detail.html`):** Kapsamlı ürün bilgisi, fiyat, stok durumu ve sepete ekleme aksiyonları.
- **REST API Hazırlığı:** Django REST Framework ve SimpleJWT entegrasyonu için yapılandırılmış modüler mimari.

---

## 🛠️ Kullanılan Teknolojiler

- **Backend:** Python, Django 5.x
- **Frontend:** Django Template Language (DTL), HTML5, CSS3, Bootstrap 5.3
- **Veritabanı:** SQLite (Geliştirme ortamı)
- **Paketler:** `djangorestframework`, `djangorestframework-simplejwt`, `django-filter`, `pillow`
